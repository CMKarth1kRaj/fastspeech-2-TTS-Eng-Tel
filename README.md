# FastSpeech 2 TTS (English & Telugu) Implementation

This repository contains the complete implementation and deliverables for the FastSpeech 2 Text-to-Speech (TTS) assignment for the Speech Recognition Internship at IIIT Hyderabad.

## Repository Deliverables
- **Synthesized Audios (`Results/`):** Custom synthesized audio WAV files for both English (E1-E4) and Telugu (T1-T4) test sentences.
- **Variance Adaptor Plots:** Detailed visual tracking of duration, pitch, and energy predictions corresponding to each generated test sentence.
- **Technical Documentation:** Comprehensive evaluation and methodologies are documented inside `Report/Technical_Report.pdf`.
